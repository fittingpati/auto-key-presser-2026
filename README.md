**Auto Key Presser Pro** — a lightweight **free automatic key presser for Windows 10 / 11**.
Pick any key, choose an interval and let the app press it for you.
Toggle it instantly with a **global hotkey** from any window — even minimized or full-screen.

Great for AFK farming in idle / incremental games (hold **W** to walk, tap **Space** to jump),
keeping the PC awake, UI / QA test loops, repetitive data entry, and any repeat-a-key routine you'd rather automate.

## Features

- 🎯 **Any key, any interval** — capture and auto-press any keyboard key, 5 ms → 10 min between presses
- ✊ **Tap or Hold** — rapid taps, or keep the key held down continuously
- 🎲 **Randomized timing** — optional ± jitter for a natural, human-like rhythm
- ⌨️ **Global F1–F12 hotkey (default F6)** — start / stop from any window, rebindable
- 🎮 **Works in games and remote sessions** — uses `SendInput` + hardware scan codes → presses land in full-screen games and RDP / VNC where older tools fail
- 🌙 **Modern dark UI** — clean, no clutter
- 🪶 **Portable & tiny** — no installer clutter, no background services
- 🆓 **Free & open** — MIT licensed, zero ads, zero telemetry

## How to use

1. Download and run the installer.
2. Click **Set Key** and press the key you want repeated.
3. Set the **interval** (ms), or check **Hold key down** for continuous press.
4. Optional: enable **Randomize ±** for jitter.
5. Hit **Start** — or press **F6** anywhere to toggle on/off.
